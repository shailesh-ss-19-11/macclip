MacClip Settings

General

Launch at login works once MacClip is installed as an app (see README).

Pasting sends ⌘V to the app you were using. macOS requires the Accessibility permission for that. Without it, items are still copied and you press ⌘V yourself.

Watches the folder macOS saves screenshots to (⌘⇧3, ⌘⇧4, ⌘⇧5). macOS may ask you to allow MacClip to access that folder (usually Desktop). Screenshots taken with ⌃⌘⇧4 already go to the clipboard and are saved either way.

History

Pinned items are never removed automatically.

Snippets

    Snippets are reusable text that never expires. Open them in the panel with Tab. You can also press ⌘S on a history item to save it.

    Privacy

      Copies made while an excluded app is in front are never saved. Text that looks like an API key, access token, private key or card number is skipped by default (pattern-based, so it can miss things). Content marked as concealed or temporary by the source app (the nspasteboard.org convention used by most password managers) is also skipped.

      macOS cannot reliably tell whether copied content is sensitive. Anything copied from an app that is not excluded is saved, so pause monitoring or exclude apps that handle secrets.

      History is stored only on this Mac, in a private folder, encrypted with AES-256-GCM. The key is a file in the same folder, so this protects against casual reading and backups, not against someone who has access to your account. Nothing is sent over the network.
